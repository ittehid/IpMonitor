# IP Monitor

**IP Monitor** — компактное Windows-приложение для локального мониторинга доступности серверов, компьютеров, сетевого оборудования и других устройств.

Программа рассчитана на постоянную работу на рабочем столе: занимает минимум места, автоматически проверяет доступность хостов, показывает их текущее состояние и ведёт журнал периодов недоступности.

Версия 2.x полностью переработана и переведена на **.NET 10 / Windows Forms**.

## Возможности

- Мониторинг доступности по **ICMP Ping**.
- Проверка доступности по **TCP-порту**.
- Состояния **Online / Warning / Offline**.
- Защита от кратковременных сбоев:
  - переход в Offline после заданного количества неудачных проверок;
  - возврат в Online после заданного количества успешных проверок.
- Warning при превышении заданного времени отклика.
- Общие и индивидуальные параметры проверки для каждого хоста.
- Индикация текущей проверки.
- Группы хостов.
- Ручная сортировка и Drag & Drop.
- Автоматическая сортировка по имени и адресу.
- Сохранение выбранного порядка после перезапуска.
- Режим обслуживания хоста без остановки мониторинга.
- Быстрое массовое добавление устройств.
- Tooltip с подробной информацией о состоянии хоста.
- Быстрый переход в Web-интерфейс устройства.
- Подключение по RDP.
- Работа в системном трее.
- Системные и звуковые уведомления.
- Автозапуск вместе с Windows.
- Импорт и экспорт конфигурации.
- Импорт старого `data.xml` из IP Monitor 1.x.
- Автоматическое резервное копирование конфигурации.

## Журнал недоступности

IP Monitor сохраняет отдельный период для каждого случая потери связи.

Для каждого периода отображаются:

- хост;
- адрес;
- время потери связи;
- время восстановления;
- продолжительность простоя.

Если связь ещё не восстановлена, запись остаётся активной, а длительность простоя обновляется автоматически.

Время потери связи фиксируется с первой неудачной проверки, после которой был подтверждён переход в Offline.

Журнал можно экспортировать в CSV.

## Режим обслуживания

Для хоста можно временно включить режим обслуживания.

Во время обслуживания:

- проверки продолжаются;
- реальное состояние хоста остаётся известным;
- аварийные уведомления временно подавляются.

Это удобно при плановой перезагрузке сервера, сетевого оборудования или других работах.

## Хранение данных

Рабочие данные хранятся в:

```text
%LOCALAPPDATA%\IpMonitor
```

Основные файлы:

```text
hosts.json
settings.json
events.jsonl
Backups\
```

`hosts.json` содержит список хостов и их параметры.

`settings.json` содержит настройки программы.

`events.jsonl` содержит журнал недоступности.

В каталоге `Backups` хранятся резервные копии конфигурации.

## Импорт из IP Monitor 1.x

Поддерживается импорт старого файла:

```text
data.xml
```

Старая версия хранит в нём название хоста и IP-адрес.

После импорта данные сохраняются в новом формате.

## Резервные копии

Автоматическое резервное копирование настраивается в программе.

Можно задать:

- включение или отключение автоматического резервирования;
- минимальный интервал создания копий;
- максимальное количество копий;
- срок хранения старых копий.

Резервные копии содержат конфигурацию хостов и настройки программы.
