# IP Monitor

**IP Monitor** — компактная программа для Windows для мониторинга доступности серверов, компьютеров, сетевого оборудования и других хостов.

## Возможности
- Проверка доступности по **ICMP Ping**.
- Проверка доступности по **TCP-порту**.
- Состояния хостов: Online, Warning, Offline, Maintenance и Disabled.
- Настраиваемое подтверждение Offline и Online после нескольких проверок.
- Warning при превышении заданной задержки.
- Общие и индивидуальные параметры мониторинга для каждого хоста.
- Ручная сортировка и Drag & Drop.
- Автоматическая сортировка по имени и адресу.
- Режим обслуживания без остановки проверки хоста.
- Быстрое массовое добавление хостов.
- Быстрый переход в Web-интерфейс.
- Подключение по RDP.
- Автоматическое заполнение Web-адреса из IP/DNS хоста.
- Работа в системном трее.
- Системные и звуковые уведомления.
- Автозапуск вместе с Windows.
- Импорт и экспорт списка хостов.
- Импорт старого `data.xml` из IP Monitor 1.x.
- Автоматические резервные копии конфигурации.
- Строгий светлый интерфейс **Business Blue**.
- Поддержка High DPI / Per-Monitor DPI.

## Журнал недоступности
IP Monitor хранит периоды недоступности хостов.

Для каждого периода отображаются:
- хост;
- адрес;
- время потери связи;
- время восстановления;
- продолжительность простоя.

Активный период недоступности обновляется автоматически до восстановления связи.
Журнал поддерживает фильтрацию, экспорт в CSV, удаление выбранной завершённой записи и очистку завершённой истории.
Активный период Offline не удаляется, чтобы не потерять данные о текущем простое.

## Быстрый доступ
Для каждого хоста можно настроить Web-интерфейс, RDP и RDP-порт.

При вводе IP-адреса или DNS-имени Web-адрес может заполняться автоматически:
```text
192.168.1.10
→
http://192.168.1.10
```
RDP использует адрес самого хоста и выбранный порт.

## Хранение данных
Рабочие данные программы хранятся в:
```text
%LOCALAPPDATA%\IpMonitor
```

Основные файлы:
```text
hosts.json
settings.json
events.jsonl
Backups\
```

## Резервные копии
Программа умеет автоматически создавать резервные копии конфигурации.
Можно настроить интервал создания копий, максимальное количество копий и срок хранения старых копий.

## Импорт из старой версии
Поддерживается импорт старого файла `data.xml` из IP Monitor 1.x.
Импортируются название хоста и его адрес, после чего данные сохраняются уже в новом формате.
